# PhD Academic Website

A clean, responsive academic portfolio designed for PhD applications and hosted on GitHub Pages.

## Included sections

- CV with **Download CV** button
- Google Scholar
- ORCID
- GitHub
- Research Statement (PDF)
- Teaching Experience
- Publications with DOI and/or PDF links
- Selected Projects
- News: papers, scholarships, awards
- Professional Service: reviewer, volunteer, TA
- Contact section
- Responsive mobile navigation
- Light / Dark mode toggle with saved preference

## Quick setup

1. Replace `Your Name`, university, email, research interests, and placeholder text in `index.html`.
2. Put your real CV at `documents/CV.pdf`.
3. Put your Research Statement at `documents/Research-Statement.pdf`.
4. Put publication PDFs in `documents/` and update the links.
5. Replace Google Scholar, ORCID, and GitHub URLs.
6. Add your own project links and news.
7. Create a GitHub repository named `YOUR-USERNAME.github.io`.
8. Upload all files in this folder to the repository.
9. In GitHub: **Settings → Pages → Deploy from a branch → main → / (root)**.
10. Your website will be available at `https://YOUR-USERNAME.github.io/`.

## Recommended content strategy for PhD applications

Keep the homepage concise. Put your strongest research evidence first:
1. Research interests
2. Publications / preprints
3. Research Statement
4. Projects / code
5. Teaching
6. Awards and news
7. Professional service

Avoid claiming publications, awards, reviewing activity, or affiliations that you have not actually completed.
